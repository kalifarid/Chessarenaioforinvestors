06 / TRUST & SECURITY

Etibar. Şəffaflıq. Ədalətli rəqabət.

Standart oyunlar üçün kamera və mikrofon məcburi deyil. Təhlükəsizlik identifikasiya, oyun analitikası və davranış yoxlamalarının çoxqatlı sistemi ilə təmin edilməlidir.

KYC Verification

Şəxsiyyət sənədinin yoxlanılması, məlumatların uyğunlaşdırılması və uyğun provayder vasitəsilə identifikasiya.

FIDE ID Verification

FIDE profilinin uyğunluğu yoxlanılır. FIDE ID-nin mövcudluğu təkbaşına hesab sahibinin şəxsiyyətini təsdiqləmir; əlavə KYC və ya uyğun yoxlama tələb olunur.

Chess Engine Analysis

Gediş keyfiyyəti, oyun statistikası, müxtəlif oyunlar üzrə davranış uyğunluğu və şübhəli nəticələrin təhlili.

Behavioral Analysis

Gediş vaxtları, qeyri-adi davranış dəyişiklikləri, şübhəli rəqib uyğunluqları və nəticə nümunələri.

Device & Session Security

Sessiya təhlükəsizliyi, eyni vaxtda hesab istifadəsi riskləri, avtomatlaşdırılmış sorğular və API sui-istifadəsinin aşkarlanması.

Human Review & Appeals

Şübhəli oyunların insan tərəfindən araşdırılması, qərarların audit tarixçəsi və apellyasiya imkanı.

Fair Play qərar mexanizmi

LOW RISK MEDIUM RISK HIGH RISK CRITICAL RISK

Təkcə mühərrikə uyğun yüksək keyfiyyətli gedişlər avtomatik bloklama üçün kifayət etməməlidir. Yüksək riskli oyunlar əlavə araşdırmaya yönləndirilməlidir.

11 / SECURITY & COMPLIANCE

Təhlükəsizlik və beynəlxalq uyğunluq.

Platformanın beynəlxalq fəaliyyəti ölkələr üzrə hüquqi və maliyyə tələblərinin ayrıca qiymətləndirilməsini tələb edir.

Platforma təhlükəsizliyi

  • HTTPS və şifrələnmiş məlumat ötürülməsi
  • Şifrələrin təhlükəsiz hash edilməsi
  • İki mərhələli autentifikasiya seçimi
  • Rate limiting və API təhlükəsizliyi
  • SQL Injection, XSS və CSRF müdafiəsi
  • Rol əsaslı giriş və audit log
  • Backup və Disaster Recovery

Hüquqi uyğunluq

  • Ölkə üzrə ödənişli yarışların hüquqi statusu
  • Yaş məhdudiyyətləri
  • KYC və AML tələbləri
  • Ödəniş provayderlərinin şərtləri
  • Vergi və istehlakçı hüquqları
  • Məlumatların qorunması
  • İcazə və lisenziya tələbləri

Paid Rooms funksiyası bütün ölkələrdə avtomatik aktiv edilməməlidir. Hüquqi baxımdan uyğun olmayan regionlarda ödənişli funksiyalar deaktiv edilə bilər. Bu təqdimat hüquqi rəy və ya fəaliyyət icazəsi deyil.
